# ✦ Cartas de Teyvat

Site estático com tradução PT ↔ EN, runas Unicode decorativas, importação de fonte, texto PUA e cartas reversíveis TYVT1.

**Atenção:** Unicode PUA (U+E100–U+E119) precisa de uma fonte instalada no aparelho receptor. Não é um alfabeto Unicode oficial de Teyvat. Para enviar a aparência verdadeira compartilhe PNG.

Para rodar: abra `index.html` ou execute `python -m http.server 8000`.

A tradução online via MyMemory requer internet e pode perder nuances. Revise antes de enviar. Projeto independente de fã.

Fontes: https://genshin-impact.fandom.com/wiki/Language ; https://github.com/SpeedyOrc-C/HoYo-Glyphs
